# Dulce Sarat — pub vidéo 20 s

`dulce-sarat-pub-20s.mp4` : format vertical 1080x1920, 30 i/s, H.264 + AAC (Reels, Stories, TikTok, YouTube Shorts).

| Temps | Plan | Texte |
|---|---|---|
| 0–4 s | Stand au marché | Dulce Sarat — Biscuits · Pickles — Faits à la main dans l'Aude |
| 3,5–7,5 s | Sachets apéritif | À l'apéritif — cumin, herbes de Provence, curry doux, emmental |
| 7–10,5 s | Sachets sucrés | Côté sucré — citron, cannelle, pépites de chocolat noir |
| 10–13,5 s | Étal de coffrets | Pickles & coffrets — légumes du soleil, aubergines, courgettes au curry |
| 13–16,5 s | Coffret de Noël | À offrir — coffrets gourmands pour toutes les fêtes |
| 16–20 s | Carton final | Logo, site, téléphone, Le Bousquet |

Musique : arpège de guitare synthétisé par le script (aucun droit à payer).

Régénérer : `pip install pillow numpy imageio-ffmpeg && python3 make_video.py`
Polices : Great Vibes et Montserrat (Google Fonts, licence SIL OFL).

## Version dynamique

`dulce-sarat-pub-20s-dynamique.mp4` (script `make_video_dynamique.py`) : 26 plans calés sur une musique à 120 BPM (batterie, basse, arpèges), gros plans découpés dans les photos, zoom et flou de mouvement à chaque coupe, mots-étiquettes rouges qui rebondissent (CUMIN, CITRON, À OFFRIR…), flashs aux changements de partie, rafale de 8 plans avant le carton final.
